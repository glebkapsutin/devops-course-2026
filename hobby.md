# Мой пет-проект

Идея: Telegram-бот для учёта личных расходов и просмотра статистики.

Стек: C#, ASP.NET Core Web API, PostgreSQL, Telegram Bot API.

Цель: научиться разрабатывать REST API, работать с PostgreSQL и интегрировать сторонние API.

## Основные функции

- Добавление расходов через Telegram-бота
- Просмотр расходов за выбранный период
- Статистика расходов по категориям
