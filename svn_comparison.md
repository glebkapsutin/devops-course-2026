# Сравнение Git и SVN

## 1. Почему создание веток в Git считается дешёвым, а в SVN дорогим?

В Git ветка является лёгкой ссылкой на определённый коммит. Создание ветки происходит быстро и практически не требует копирования файлов.

В SVN ветки традиционно создаются как копии каталогов в репозитории. Поэтому операция ветвления может быть более тяжёлой и требовать дополнительных операций с репозиторием.

## 2. Можно ли сделать commit в SVN без интернета? Почему?

Нет, стандартный commit в SVN требует подключения к центральному репозиторию. SVN использует централизованную архитектуру, поэтому изменения отправляются непосредственно на сервер.

В Git commit можно сделать без интернета, потому что история и репозиторий находятся локально. Интернет нужен, например, для push изменений на удалённый репозиторий.

## 3. Когда SVN всё ещё может быть предпочтительнее Git?

SVN может быть удобнее в проектах, где требуется централизованный контроль версий и единый серверный репозиторий. Также SVN может использоваться в существующих корпоративных проектах, инфраструктура которых уже построена вокруг SVN.

Git обычно предпочтительнее для современной разработки благодаря распределённой архитектуре, удобной работе с ветками и возможности работать с историей проекта локально.
